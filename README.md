# 图像滤波工具箱

一个基于 OpenCV 的单文件图像处理工具：选择图片文件夹后，用滑杆切换 17 种处理模式，实时对比原图与结果。

## 功能

- 递归读取文件夹中的 `.jpg`、`.jpeg`、`.png`、`.bmp`
- 17 种处理模式：滤波、阈值、直方图均衡、亮度/对比度、噪声、几何变换
- 预览窗口只放 `filter` 滑杆，参数窗口按当前模式动态生成对应滑杆
- 左侧原图、右侧处理结果实时对比
- 所有结果统一存为 PNG
- 快捷键操作


## 目录结构

```text
image_toolbox_init/
├── README.md
├── samples/              # 测试图片
│   ├── shapes.png
│   ├── texture.jpg
│   ├── lowcontrast.png
│   ├── lowcontrast_gray.png
│   └── sub/grid.bmp
└── src/
    └── simple_gui.py     # 全部代码
```

运行后默认在所选图片目录的上一级生成 `output_sample/`。

## 环境要求

- Python 3.10+
- OpenCV（`opencv-python`，需要带 HighGUI，能弹出窗口）
- NumPy
- Tkinter（仅用于选择文件夹和输出目录）

```bash
python3 -m pip install opencv-python numpy
```

Linux 如果提示找不到 tkinter：

```bash
sudo apt install python3-tk
```

Windows / macOS 的官方 Python 安装包通常自带 Tkinter。

无图形界面的环境（纯 SSH 服务器、CI 等）无法弹出 OpenCV 窗口和 Tk 对话框，需要图形桌面或 X11/Wayland 转发。

## 运行

```bash
cd image_toolbox_init
python3 src/simple_gui.py
```

需要在项目根目录运行：默认的 `samples/` 和 `output_sample/` 都按相对路径解析。

启动后会弹出文件夹选择框：

- 选择包含图片的文件夹即可开始
- 直接取消则使用自带的 `samples/`

不需要任何命令行参数。

## 界面说明

程序会打开两个窗口：

| 窗口 | 标题 | 内容 |
| --- | --- | --- |
| 预览窗口 | `Image Filters` | 左右对比图 + `filter` 滑杆，标题显示当前模式、序号/总数和文件名 |
| 参数窗口 | `Params` | 当前模式用到的参数滑杆|

- 切换 `filter` 后会重建参数窗口，参数回到该模式的默认值，不会保留上一次的调整；
- 当前模式用不到的滑杆不会显示，内部按默认值计算；
- 预览左右各占一半，每边最大约 542×620 且不放大，中间是 16 px 深灰间隔，高度不足时用深灰补齐。

## 模式与参数

| 序号 | 模式 | 参数滑杆 | 行为 |
| --- | --- | --- | --- |
| 0 | 原图 | 无 | 原样输出，用于对比 |
| 1 | 灰度 | 无 | BGR 转单通道灰度 |
| 2 | 高斯滤波 | `ksize` 5..31（默认 5）、`sigmaX` 0..100（默认 0） | `ksize` 偶数自动加 1；`sigmaX/10` 为实际标准差（0..10），为 0 时由 ksize 自动计算 |
| 3 | 中值滤波 | `ksize` 5..31（默认 5） | 偶数自动加 1；核越大去噪越强、也越模糊 |
| 4 | 双边滤波 | `d` 9..30（默认 9）、`sigmaColor` 75..200（默认 75）、`sigmaSpace` 75..200（默认 75） | 直接对应 `cv2.bilateralFilter`；`d` 越大越慢 |
| 5 | Canny 边缘 | `threshold1` 80..255（默认 80）、`threshold2` 160..500（默认 160） | 低/高阈值，高阈值通常取低阈值的 2~3 倍；输出单通道边缘图 |
| 6 | 自适应阈值 | `blockSize` 5..31（默认 5）、`C` 0..20（默认 0） | `blockSize` 偶数加 1、最小 3；`C` 为从局部均值减去的常数，越大越暗；高斯加权 |
| 7 | 二值化 | `thresh` 128..255（默认 128） | 像素 > `thresh` 置 255，否则置 0（`THRESH_BINARY`） |
| 8 | 固定阈值二值化 | `thresh` 128..255（默认 128） | 实现与「二值化」相同 |
| 9 | 直方图均衡化 | 无 | 转灰度后 `equalizeHist` |
| 10 | CLAHE局部均衡 | `clipLimit` 2..10（默认 2）、`tileGridSize` 8..32（默认 8） | `clipLimit` 越大对比越强、噪声越明显；`tileGridSize` 为分块边长，越大越接近全局均衡；先转灰度 |
| 11 | 亮度/对比度 | `alpha` 10..30（默认 10）、`beta` 0..255（默认 0） | 实际增益 `alpha/10`（1.0..3.0），`beta` 为亮度偏移（0..255，只能加亮） |
| 12 | 椒盐噪声 | `prob` 1..50（默认 1） | 噪声比例 `prob/1000`（0.1%..5%），黑白各半，每次重绘重新随机 |
| 13 | 旋转 | `angle` 0..360（默认 0） | 绕图像中心旋转，正值逆时针；画布尺寸不变，边角会被裁掉 |
| 14 | 等比缩放 | `scale` 5..30（默认 5） | 缩放比例 `scale/10`（0.5..3.0），使用 `INTER_AREA`；默认值即缩小到一半 |
| 15 | 中心裁剪 | `ratio` 30..100（默认 30） | 保留比例 `ratio/100`（0.3..1.0），居中裁剪 |
| 16 | 镜像翻转 | `flipCode` 0..2（默认 0） | 0 左右、1 上下、2 双向（映射为 `cv2.flip` 的 1/0/-1） |

说明：

- 滑杆名与 OpenCV 函数参数名一致（`ksize`、`sigmaX`、`threshold1`、`threshold2`、`blockSize`、`thresh` 等），滑块值到实际参数的换算见「行为」列；
- 灰度、Canny、自适应阈值、二值化、直方图均衡化、CLAHE 输出单通道图，预览时会临时转成 BGR，保存的仍是灰度 PNG；
- 旋转、缩放、裁剪、翻转只影响输出结果，不修改原文件；
- 切换模式后参数重置为该模式的默认值（见上表括号内的默认值）。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `]` | 下一张（循环） |
| `[` | 上一张（循环） |
| `s` | 保存当前处理结果 |
| `b` | 批量处理当前图片列表 |
| `k` | 选择输出目录 |
| `o` | 重新选择输入文件夹（同时重置输出目录） |
| `q` / `Esc` | 退出 |

## 输出规则

- 默认输出目录：所选图片目录的上一级 `output_sample/`，不存在时自动创建；
- 按 `k` 可把输出目录改成任意文件夹；按 `o` 换输入文件夹后，输出目录会重置为新目录同级的 `output_sample/`；
- 文件名格式：`原文件名_模式名.png`，例如 `shapes_gaussian.png`；
- 批量处理遍历当前输入文件夹递归扫描到的全部图片，输出保持扁平结构，不保留子目录；
- 同名结果直接覆盖；
- 所有结果统一存为 PNG，原始图片不会被修改。

## 说明

- 一次只应用一种处理，不支持多步串联；
- 批量处理是顺序执行的，处理期间窗口会卡住，终端会打印 `[i/n] 文件名 -> 结果名` 进度；
- 预览时如果当前图片读取失败，程序会直接退出；批量处理时则打印提示并跳过该文件；
- 参数窗口每次切换模式都会重建，滑杆值不会跨模式保留；
- 「二值化」与「固定阈值二值化」目前实现相同，参数都是 `thresh`；
- 直接使用 `cv2.imread` / `cv2.imwrite`，没有做中文等特殊路径兼容处理。
